# Opposé d’une somme ou d’une différence

>[!propriete] Propriété : 
>L’opposé de $(a+b)$ est égale à la somme des opposés.
>$$-(a+b)=-a-b$$
>De la même manière :
>$$-(a-b)=-a+b$$

>[!remarque] Remarque :
>Quand on a un signe « - » devant une parenthèse, on change le signe de tous les termes à l’intérieure de la parenthèse.

>[!exemple] Exemples :
>- Avec une somme : $-(3x + 4) = -3x - 4$.
>- Avec une différence : $-(-5x + 2) = 5x - 2$
