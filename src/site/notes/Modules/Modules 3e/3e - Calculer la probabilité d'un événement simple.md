# Calculer la probabilité d'un événement simple
>[!definition] Définition :
>Si toutes les issues d’une expérience aléatoire ont la même probabilité, l’expérience est dite **équiprobable**.

>[!propriete] Propriété :
>Dans une expérience aléatoire ou toutes les issues sont équiprobables, la probabilité d’un événement $E$ est :
>$$P(E)=\frac{\text{Nombre d'issues favorables}}{\text{Nombre d'issues totales}}$$

>[!exemple] Exemple :
>Une urne contient 3 boules vertes et 5 boules jaunes. 
>Quelle est la probabilité de l’événement $J$  : `tirer une boule jaune` ?
>Issues favorables : les 3 boules jaunes.
>Issues totales : les 8 boules.
>La probabilité de tirer une boule jaune est donc : $P(J)=\frac{3}{8}$.
