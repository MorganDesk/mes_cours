# Formules de distributivité simple
>[!propriete] Propriété : Distributivité simple
>Pour tous nombres *k*, *a* et *b* :
>$$k(a+b)=ka+kb$$
>et 
>$$k(a-b)=ka-kb$$

>[!remarque] Rappel :
>La distributivité simple peut être utile pour le [[Modules/Modules 5e/5e - Distributivité simple et calcul réfléchi\|calcul réfléchi]].
## Développer
>[!definition] Définition : 
>**Développer** c’est transformer un produit en une somme ou une différence.
>Pour cela, on utilise les formules de distributivité.

>[!exemple] Exemple :
>1. Développer $A=3(2x+1)$ :
>$$\begin{aligned}A&=3 \times 2x + 3 \times 1\\&=6x+3\end{aligned}$$
>2. Développer $B=x(3x-4)$ :
>$$\begin{aligned}A&=x \times 3x - x \times 4\\&= 3x^2-4x\end{aligned}$$
