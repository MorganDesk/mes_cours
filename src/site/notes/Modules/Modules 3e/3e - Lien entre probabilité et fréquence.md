# Lien entre probabilité et fréquence
>[!propriete] Propriété : (admise)
>Si on répète un très grand nombre de fois une expérience aléatoire, la fréquence d’apparition d’une issue se rapproche de la probabilité de cette issue.

>[!exemple] Exemple :
>Chaque élève lance 20 fois un dé équilibré à 6 faces.
>
>| Face                       | 1   | 2   | 3   | 4   | 5   | 6   |
>| -------------------------- | --- | --- | --- | --- | --- | --- |
>| **Probabilité (décimale)** |     |     |     |     |     |     |
>| **Effectif**               |     |     |     |     |     |     |
>| **Fréquence**              |     |     |     |     |     |     |
>
