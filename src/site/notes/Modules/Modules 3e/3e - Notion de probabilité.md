# Notion de probabilité
>[!propriete] Propriété : (admise)
>La probabilité d’un événement $A$ est un nombre compris entre 0 et 1 et se note $P(A)$.

>[!definition] Définitions :
>- Un événement est dit **impossible** si sa probabilité est nulle (si $P(A)=0$).
>- Un événement est dit **certain** si sa probabilité est 1 (si $P(A)=1$).

>[!exemple] Exemple :
>Si on lance un dé à 6 faces :
>- L’événement `Obtenir un nombre entier` est certain.
>- L’événement `Obtenir 7` est impossible.

>[!remarque] Remarque :
>On peut exprimer une probabilité sous plusieurs formes : nombre décimal, fraction, pourcentage.
